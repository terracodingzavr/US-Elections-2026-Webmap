## Код, данные и зависимости

- src/index.js создаёт React root и подключает App, глобальный CSS и web-vitals. App_base.js — отдельная, не импортируемая в точке входа версия. В App.css и index.css остались пересекающиеся правила слайдера.
- public/data содержал 12 GeoJSON. В выборках насчитывается 124–126 административных районов, 3 353–3 578 УИК, 15 объектов в district_gdcandidat_2021. Среди файлов есть старый elections-2012.geojson с полем IO_ID. Скрипт import json.py пересчитывает доли партий и использует абсолютные пути Windows. Часть файлов из опубликованной ветки отсутствует в main.
- Совместимая связка по peerDependencies: React 19.1.0, React DOM 19.1.0, React-Leaflet 5.0.0, Leaflet 1.9.4. React Slider 2.0.6 заявляет React 16–18, npm выдаёт предупреждения о конфликте. Один цикл не требует слайдера.
- MapLibre присутствует в файле App.test.js, который содержит ранний прототип вместо тестовых случаев. Прямой запуск Jest завершился на импорте MapLibre: в jsdom нет window.URL.createObjectURL. D3-array не используется в основном App.js. Для нового приложения эти зависимости не нужны.
- В корне московского репозитория нет отдельного LICENSE. Новый проект указывает авторство и ссылку на источник. Включение московских наборов и исходных файлов в новую сборку не требуется.
