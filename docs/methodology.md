# Методика расчёта

Доля кандидата равна его голосам, делённым на учтённые голоса в гонке, в процентах. Голоса разных кандидатов одной и той же партии суммируются. Преимущество D–R равно 100 × (голоса D − голоса R) / все учтённые голоса в гонке. Сторонние кандидаты входят в знаменатель. При неполном наборе голосов или отсутствии данных по одной из двух партий показатель остаётся пустым.

Лидер определяется по наибольшему количеству опубликованных голосов. При равенстве двух ведущих кандидатов отмечается ничья. Разрыв двух лидеров выражен в процентных пунктах и учитывает кандидатов любых партий. Для сертифицированного результата может быть указан официальный победитель. Для Аляски, округа Колумбия и гонок Палаты представителей в Мэне с рейтинговым голосованием показываются первые предпочтения с соответствующей пометкой. Медийные прогнозы не определяют победителя на карте.

На уровне штатов для Палаты представителей складываются голоса округов с полными сопоставимыми подсчётами. Сводный показатель доступен только при наличии сопоставимых данных по всем округам штата. Наличие нескольких источников и предварительный статус отражаются в карточке. В штатах с одним округом показывается та же гонка. Округ Колумбия показывает отдельные результаты делегата без решающего голоса.
