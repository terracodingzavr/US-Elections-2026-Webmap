# Словарь данных

## Геометрия

| Поле | Смысл |
| --- | --- |
| geoid | Идентификатор Census, строка из двух знаков для штата и четырёх для округа |
| stateFips, fips | Двухзначный код штата или DC |
| code, name, ru | Почтовый код, английское и русское названия |
| district | Номер округа, 00 для at-large, 98 для DC |
| delegate | Булев признак округа делегата |
| congress, boundaryFile | Номер Конгресса и архив геометрии округа |

## Итоги

Файлы house_results_2026.json и senate_results_2026.json содержат year, snapshotDate и массив races.

| Поле | Смысл |
| --- | --- |
| id | Уникальный идентификатор гонки |
| office, kind | Палата и тип гонки general / special |
| geoid, stateFips | Ключ геометрии и код штата |
| status | official-preliminary, aggregated или certified |
| source, url, contest | Название источника, HTTPS-ссылка и исходное имя гонки при наличии |
| updatedAt, retrievedAt | Метки ISO 8601 с часовым поясом, null при неизвестном времени |
| basis | first-choice, если в записи используются первые предпочтения |
| totalVotes | Знаменатель голосов в гонке, null при отсутствии достоверного значения |
| absentMajorParties | Список подтверждённых отсутствующих основных партий для расчёта сводки штата |
| ballotSourceUrl | Источник сведений о кандидатах и их партийной принадлежности |
| noBallot | Подтверждённая победа единственного кандидата без голосования |
| winnerName | Имя официально объявленного победителя, если известно |
| candidates | Массив с name, party, partyRaw и votes |
| party, partyRaw | D, R, other или null, плюс исходное обозначение |
| votes | Число голосов или null при отсутствии |

Разницу, доли и лидера вычисляет приложение по первичным полям. Если в штате несколько гонок Сената, geoid может повторяться, а id остаётся уникальным. Выбор гонки реализован в карточке территории.
